# AIList v0.1
Один экземпляр обслуживает одно домохозяйство. Для независимых семей разворачиваются отдельные Compose-проекты с собственными секретами и томами.

Браузер (Svelte 5 + TS) и опциональный Telegram-бот используют общий доменный слой Go. PostgreSQL хранит партии, единицы, места, сроки, журнал и ключи повторных запросов. Ручной учёт работает без моделей. Текст проходит через заменяемый OpenAI-compatible chat endpoint, голос сначала через faster-whisper. Модель предлагает строго типизированные операции. Пользователь проверяет их перед записью. Поиск и списки читают фактические остатки из БД.

## Roadmap
1. Домен и HTTP API, атомарные пакеты изменений и повторная доставка.
2. Текстовые команды, поиск и голос, личные чаты Telegram с allowlist.
3. Двуязычный веб-клиент, партии со сроком, покупки и история.
4. Compose, проверки с PostgreSQL, сборка и релиз.
5. После v0.1 — Алиса, приглашения и роли, уведомления о сроках.

## v0.2.0 — исправление черновиков
Веб-клиент редактирует копию выбранной операции. В Telegram callback содержит номер строки и идентификатор версии черновика. Ответ на запрос бота обновляет версию под блокировкой строки PostgreSQL. Подтверждение читает эту же строку и применяет операции в одной транзакции. Повторная доставка подтверждения использует существующий ключ идемпотентности. Исправление обходится без вызова LLM.
