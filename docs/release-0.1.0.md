Первый MVP AIList. Ручной учёт, голосовые и текстовые команды, подтверждение изменений, поиск, сроки годности, покупки и журнал операций. Веб-клиент RU/EN и опциональный Telegram-бот используют одну PostgreSQL. Инструкция запуска и подключения локальных моделей находится в README.

Проверены атомарность и повторная доставка с PostgreSQL, ручное внесение через Chromium, реальное распознавание WAV на CPU и текстовая команда через локальный llama.cpp с Qwen2.5-1.5B-Instruct Q4_K_M. Telegram проверен на уровне обработки сообщений и подтверждения записи. Для подключения личного чата нужны собственные токен бота и allowlist.
