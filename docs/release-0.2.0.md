# Редактирование отдельных позиций
- В веб-клиенте можно исправить любое поле строки и проверить весь список перед записью.
- В Telegram нажмите номер с карандашом и ответьте названием, количеством и единицей. Подтверждение доступно кнопкой и командой.
- Обновлённый черновик получает новую версию. Кнопка старого сообщения не применит устаревшие данные. Повторное подтверждение не удвоит остатки.
- Поддержаны русский и английский. Изменения используют существующую схему PostgreSQL и не требуют повторного вызова модели.

Обновление с v0.1.0 и примеры приведены в README.
